# AGENTS.md

## Project Vision

This project is not a traditional portfolio.

It is a living research environment that documents the evolution of knowledge,
projects, experiments, and personal thinking over time.

The goal is not to convince visitors that the author knows everything.

The goal is to demonstrate curiosity, engineering methodology, critical thinking,
and continuous learning.

Everything should reinforce this idea.

---

# Core Principles

When making changes, always ask:

- Does this help communicate the author's way of thinking?
- Does this encourage exploration?
- Does this feel like a research institute rather than a marketing website?
- Does this preserve clarity?

If the answer is no, reconsider the implementation.

---

# Visual Identity

Inspired by:

- Scientific laboratories
- Research institutes
- Arknights (especially Rhine Lab)
- Engineering documentation
- Technical manuals
- Modern architecture
- Botanical research facilities

Avoid:

- Startup landing page aesthetics
- Excessive gradients
- Excessive glassmorphism
- Unnecessary animations
- Skill percentage bars
- Generic portfolio templates
- "Hire Me" marketing language

The atmosphere should communicate:

- Precision
- Curiosity
- Calm
- Research
- Continuous evolution

---

# Design Language

Prefer:

- Clean layouts
- Strong alignment
- Large negative space
- Thin dividers
- Technical labels
- Metadata
- Information hierarchy
- Grid systems

Every page should resemble a research document.

---

# Color Philosophy

Colors have semantic meaning.

Neutral colors dominate.

Accent colors indicate information rather than decoration.

Example:

Blue → Information

Green → Growth

Orange → Warning

Red → Critical

Never use color only because it looks good.

---

# Typography

Typography should feel technical.

Hierarchy is essential.

Suggested pairing:

Headings:
- Oswald
- IBM Plex Sans Condensed

Body:
- Inter
- IBM Plex Sans

Code:
- JetBrains Mono

Use uppercase only for labels and metadata.

Avoid decorative fonts.

---

# Motion

Animation should communicate state.

Never animate for decoration.

Allowed:

- Fade
- Small transitions
- Layout transitions
- Expand/collapse

Avoid:

- Floating effects
- Infinite animations
- Heavy parallax
- Large entrance animations

The interface should feel stable.

---

# Components

Every component should communicate information.

Cards should resemble technical sheets.

Prefer metadata over marketing.

Example:

PROJECT

Equitas

STATUS
Active

FIELD
Financial Analysis

LAST UPDATE
2026-07-11

Instead of:

"Awesome AI platform"

---

# Content Philosophy

Content is more important than visuals.

Projects should explain:

- Problem
- Motivation
- Research
- Architecture
- Decisions
- Challenges
- Results
- Future improvements

Articles should encourage understanding rather than tutorials.

---

# Knowledge Graph

Whenever possible, connect information.

Projects should reference:

- Articles
- Experiments
- Books
- Technologies
- Related ideas

Articles should reference projects.

The website should behave like a knowledge network rather than isolated pages.

---

# Writing Style

Write like an engineer documenting discoveries.

Avoid marketing language.

Avoid exaggerated claims.

Prefer:

"I investigated..."

"I experimented with..."

"My conclusion was..."

"I would approach this differently today..."

The evolution of thought is valuable.

Do not hide mistakes.

---

# User Experience

Visitors should feel like they entered:

A research laboratory.

Not:

A software agency.

Navigation should encourage curiosity.

Discovery is more important than conversion.

---

# Accessibility

Accessibility is mandatory.

Maintain:

- Proper contrast
- Semantic HTML
- Keyboard navigation
- Reduced motion support
- Screen reader compatibility

---

# Performance

Performance is part of the design.

Avoid unnecessary dependencies.

Prefer CSS over JavaScript when possible.

Lazy-load large assets.

Animations must remain smooth.

---

# Philosophy

The website documents a person, not a résumé.

It should reveal:

How ideas emerge.

How projects evolve.

How knowledge connects.

How the author grows over time.

Every contribution should reinforce this mission.
