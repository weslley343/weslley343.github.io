# Sistema de Automação Doméstica

Este é um projeto desenvolvido para integrar dispositivos IoT dentro de uma residência, utilizando Python para o backend e rodando completamente em containers Docker para fácil escalabilidade.

## Principais Desafios

O maior desafio foi conseguir criar um protocolo leve e rápido capaz de se comunicar com microcontroladores ESP32 sem consumir muita energia.
