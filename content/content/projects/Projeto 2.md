# Dashboard Analítico de Vendas

Neste projeto eu construí um dashboard iterativo com o foco na visualização de dados em tempo real utilizando NextJS e gráficos modernos.

O layout conta com um estilo glassmorphism, adaptando-se a temas claros e escuros de acordo com as preferências do sistema operacional do usuário.
